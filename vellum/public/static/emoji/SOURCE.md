# Emoji accents

Microsoft Fluent Emoji, 3D style, from https://github.com/microsoft/fluentui-emoji
(commit 1ffb34c752ecf5d402f04cfb4b392c77f57c54bc), under the MIT license in `LICENSE` beside this file.
Each picture is the original 256x256 PNG, renamed to its code points
(presentation selector left out). The palette that uses them is
`src/lib/slides/emoji-accents.ts`.
